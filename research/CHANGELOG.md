# Blackbox v0.2

This version implements the engineering fixes identified in the v0.1 review, under the user's Windows/Docker Desktop/WSL2 and two-hour CPU budget.

- Hard constraints now have explicit type, category, nonempty-array and range checks. Observable event references and timestamps are validated before a decision.
- Cache identity covers generator/collection/feature/label code and episode settings; cache payloads have content digests.
- Models and answer samplers are immutable release bundles, selected by an atomic deployment pointer. Serving checks transform identity as well as file hashes.
- Episode ownership uses leases and heartbeats. Stale owners cannot commit. Failed/interrupted attempts are retained. The supervisor also uses an OS-held exclusive workflow lock.
- Evaluations reject asset changes during an episode and source/asset changes across an episode. Frozen test plans include exact inference release identity.
- Release checks recompute required matrix membership and scalar outcome/coverage consistency from episode records. Raw failures remain visible after retries.
- Test counts come from actual unittest execution. The public snapshot checker is run and its byte hashes are rechecked for readiness.
- Docker records refer to the exact built image ID, policy mode and release manifest. Asset ownership and readable release-directory permissions support the unprivileged runtime user.
- Fallback diagnostics distinguish no opportunities, empty answer model, search deadline, solver deadline, unavailable solver, failed process and invalid incumbent/output.
- The Windows launcher supervises a bounded workflow with phase logs, deadline cleanup, and an explicit incomplete status. It never reduces a matrix to manufacture success.

The default remains conservative. This is not a claim that the newly fitted scorer improves MSMI or that Docker/Windows/hosted CI has run in the authoring environment. Current measured evidence is in results/REPORT.md; prior and interrupted development evidence are kept separately under evidence/.
